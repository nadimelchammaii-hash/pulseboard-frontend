description Description

Configure persistent WebSocket subscription for the notification channel with immediate push dispatch. Requires resilient token refresh heartbeat and automatic exponential backoff retry.

Key Specifications:
  • Reconnection interval: jittered exp-backoff (1s - 30s)
  • Heartbeat Ping: every 30,000ms (auto-terminate if pong missing)
  • Graceful degradation: Seamless fallback to HTTP long-polling on firewall block
